# blink1forteams
Controll blink(1) USB light depending on teams status icon in windows tray


## SETUP

> NOTE
> Only works on Windows

1. Chechout repository
2. Create environenment `python3 -m venv env`
3. Activate environment `.\env\Scripts\activate`
4. Install dependencies `pip install -f requirements.txt`
5. Make sure you have blink1 dependencies installed (https://github.com/todbot/blink1-python)[https://github.com/todbot/blink1-python]
